# Machine Learning Labs

This repository contains practical machine learning labs covering supervised and unsupervised learning techniques. The exercises include implementing algorithms, training models, visualizing results, and evaluating model performance using Python and Jupyter Notebooks.

A **key goal** of these labs is to understand the underlying concepts: the fundamental algorithms and learning procedures are implemented from **scratch** where appropriate, rather than relying only on high-level machine learning functions. Standard libraries are used for numerical operations, visualization, testing, and selected model workflows.

## Topics Covered

1. **Linear Regression with One Variable**
   - Cost functions
   - Gradient descent
   - Model prediction and visualization

2. **Linear Regression with Multiple Variables**
   - Feature scaling
   - Multiple-variable gradient descent
   - Housing price prediction

3. **Logistic Regression**
   - Binary classification
   - Sigmoid function
   - Decision boundaries
   - Regularization

4. **Neural Networks**
   - Forward propagation
   - Neural network classification
   - Model training with Keras

5. **Evaluation of Machine Learning Experiments**
   - Model evaluation
   - Training, validation, and test sets
   - Bias and variance
   - Experiment design

6. **Support Vector Machines**
   - Classification with SVMs
   - Decision boundaries
   - Dataset comparison

7. **K-Means Clustering**
   - Unsupervised learning
   - Centroid initialization
   - Data clustering and visualization

## Technologies

- Python
- Jupyter Notebook
- NumPy
- Matplotlib
- scikit-learn
- TensorFlow / Keras

## Getting Started

Clone the repository and install the required Python packages:

```bash
pip install numpy matplotlib scikit-learn tensorflow jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Then open the notebook for the lab you want to study.

## Purpose

These labs were completed as part of a machine learning course to develop practical experience with fundamental machine learning algorithms and workflows, from data preprocessing and model training to evaluation and visualization.
